# 验证说明

## 基础硬件与回归记录

在ESP32-S3-ePaper-3.97上，早期0.1.x版本已完成ESP-IDF 6.0.2构建、16 MB Flash写入校验、8 MB PSRAM启动测试、SHTC3采样、屏幕刷新与拨轮操作验证。原生USB选择器通过VID/PID与本地指定序列号锁定目标，不依赖固定COM号。

历史问题已作为回归重点保留：

- 100 Hz系统时钟会将2毫秒等待取整成零；温湿度唤醒等待向上取整，并有限重试。
- 字号不是完整字形高度；字库生成器测量字形实际墨点边界和统一基线，逐字检查无墨点丢失。
- 电脑成功获取额度不等于设备已配对；必须配置网关地址和令牌，再确认设备返回同步成功。
- 缺失的Codex额度窗口不填0%；接口失败保留缓存并显示原始取得时间。
